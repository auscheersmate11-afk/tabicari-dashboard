# 旅キャリ 共有リストダッシュボード

共有顧客リスト（Googleスプレッドシート）の「顧客リスト」タブを、ページを開いたときに読み込んで集計するダッシュボードです。

- 送信 → 返信 → 面談希望 → 日程確定 → 一次面談 → 二次面談希望 → 二次面談実施 → 成約 の8ステージ
- 期間（全期間/30日/14日/7日）と担当者で絞り込み
- 担当者ランキング（上位10人＋検索・並べ替え・すべて表示）
- 日別の送信数と返信数
- 入力の抜けチェック（担当者・日付・ユーザー名）
- みんなへの貢献ランキング（Discordのコメント・押したスタンプ・もらったスタンプ。`me/community.json` を読む。貢献ポイント＝コメント＋押したスタンプ。これまで／直近7日。上位3人は表彰台＋紙吹雪など。下に目標達成グループ別の合計と1人あたり）

個人のユーザー名はページに表示しません。読み込みには、スプレッドシートの共有設定が「リンクを知っている全員」になっている必要があります。

`?demo=1` を付けるとサンプルの数字で表示します。

## 個別専用ページ（me/）

担当者ひとり分の数字（送信数・返信・面談・成約・メッセージ別・日ごと・チーム平均との比べ）を見るページ。

- URL：`https://auscheersmate11-afk.github.io/tabicari-dashboard/me/?p=<トークン>`
- トークン＝名前から作るハッシュ（スペース・髙/高・かっこの表記ゆれはそろえてから計算）。名簿はページに持たず、顧客リストの担当者名と「LINE案内」タブのお名前をハッシュして一致した人を表示する
- 人が増えたら「LINE案内」にお名前を足して `python3 tools/make_links.py` を実行し、出たURLを「個別専用ページ」列に入れる
- 「みんなへの貢献」：旅キャリDMチーム（Discord）でのコメント（返信も含めた投稿すべて）・押したスタンプ・もらったスタンプ。`me/community.json`（キーはURLと同じトークン・名前は入れない）を ~/cm-discord-archive/tabi_community.py が毎朝作って push する
- 「いまの状況」に、いまの遅れ（今日までの目標との差）・目標まであと何通・1日のペース（送るべき数といまの平均の差）と進み具合のバー。「日ごとの送信」のグラフには目標ペースの線。月500通が目標で、2026年10月だけ特別に10月の分も11月に入れて「11月末までに500通」（今日までの目標は11/1から11/30まで毎日同じ数ずつ積み上げた数。10月中に送った分は先取り扱い）。12月からは毎月500通で前の月の分は足さない（me/index.html の goalPeriod）
- 上の「最新の数字にする」ボタンで、その場でシートを読み直す（Discordの数は毎朝の更新分）
- `?p=demo` でサンプル表示

## 運営ハブ（hub/）

運営用の入口。`https://auscheersmate11-afk.github.io/tabicari-dashboard/hub/` で、運営ボード（ops/）・DMダッシュボード（claude.ai）・共有ダッシュボード（トップ）をタブで切り替える。

- 運営ボードと共有ダッシュボードはページの中に埋め込んで表示（タブを開いたときに初めて読み込む）
- DMダッシュボードは dm/（下）を埋め込む（claude.ai 版は埋め込みが禁止されているため GitHub に移した）
- `#ops` `#dm` `#share` を付けると最初に開くタブを指定できる。付けなければ前回見たタブ

## DMダッシュボード（dm/）

claude.ai にあった「旅キャリ DMダッシュボード」の GitHub 版。`https://auscheersmate11-afk.github.io/tabicari-dashboard/dm/`

- 旅キャリ 抽出リストの「リスト」タブを、ページを開いたときにブラウザから直接読む（DM文などの長い列は読まない）。数字はページに保存しない
- 上の「最新の数字にする」でその場で読み直す
- 施策メモは `dm/notes.json`（ページからは編集できない。追加・終了・結果の記入は Claude に頼んで notes.json を直す）

## 旅キャリGo（go/）

アポインターがスマホ1つで「配られた人に1通目を送る → 共有顧客リストに記録」まで終わらせるアプリ。`https://auscheersmate11-afk.github.io/tabicari-dashboard/go/#k=<合言葉>`

- 画面はこの `go/index.html` 1枚。データの出し入れは Apps Script「旅キャリ 配布」の `tg_api.gs`（Webアプリ）。毎朝の配布は同じプロジェクトの `td_distribute.gs`（手元の正本は `~/tabi_carry_distribute/`）
- 合言葉は1人ずつ（スクリプトプロパティ `TG_KEYS`）。URLの `#k=` はサーバーに送られない部分なので、GitHub Pages のログにも残らない。名簿や送り先のデータはこのページに持たない
- 今日：配られた送り先のカード →「コピーしてInstagramを開く」（文章をコピーして `ig.me/m/ユーザー名` を開く）→ 貼り付けて送る →「送信済み」で共有顧客リストに1行（日付・担当者・ユーザー名・URL・メッセージA〜D）。「あえて送らない」は理由を選ぶ
- さがす：自分で見つけた相手の**ユーザー名**を入れて重複チェック（2026-11-10〜 ユーザー名の入力欄。先頭の @ は不要・URLを入れても読める）→ まだ誰も送っていなければ、送ったあと「送った！」で共有顧客リストに記入
- 自分：個別専用ページ（me/?p=…・LINE案内タブ D列と同じURL）をそのまま中に出す（2026-11-10〜・iframe・同じサイトなので高さは中身に合わせる）。デザインも数字も個別専用ページと同じ
- 1日40通まで・15通ごとにひと休み。ランク（A/B/C）は出さない
- `?demo=1` で架空のデータの見本（どこにも記録しない）
